# Student Records Database Design

This repository contains an academic database project designed for managing a large-scale student dataset (300,000+ records). The project focuses on database design, ER modeling, normalization (1NF → 3NF), and writing sample SQL queries.

## Purpose
The goal of this project is to demonstrate:
- Database schema design
- Entity-Relationship modeling
- Normalization for efficient relational structure
- Writing structured SQL queries for common database tasks

## Folder Structure
- `schema/`             → ER diagrams (PDF or images)
- `normalization/`      → Normalized schema (1NF–3NF)
- `queries/`            → Sample SQL queries (structure only, no raw data)

## Key Concepts
- Relational database design
- Entity-Relationship modeling
- Database normalization (1NF, 2NF, 3NF)
- SQL queries (SELECT, JOIN, GROUP BY, WHERE)

## Notes
- Raw dataset is **not included** for privacy and data protection
- Focus is on database design and query skills rather than data storage
